== world lock (series M) ==
The platform cache area ~/.experiments/cache/env-prep carries one
master per meaning×stack combo (twenty _*-m-* masters); every wave
copies, never builds. The cpp stacks read the platform prefix
~/.local. Cells: python on pyenv 3.12.12, js on the system node,
rust vendored (resolution and build purely from the cell's copy),
go through the cell's file proxy, cpp from the prefix headers plus
the vendored hiredis sources; network closed by rule and by
construction. Every cell brings its own PostgreSQL and Redis up as
service files (env/service/{pg,redis}.sh) on unix sockets inside
the cell's scratch — listen_addresses empty, --port 0: no TCP
listener exists anywhere in a wave.

-- the loopback port scheme (cells.py; unique across a wave's ten
cells, one wave at a time by the series law)
SERVE_PORT = 18100 + cell index (every cell's HTTP face); a
conduit cell also INGRESS/EGRESS/TARGET_PORT = 18300+3i .. 18302+3i
(route listeners and the bench target). Both ranges sit below the
OS's ephemeral span (32768+), so the OS hands out no collisions
either.
