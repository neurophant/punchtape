# 词汇表
[English](GLOSSARY.md) · [Русский](GLOSSARY.ru.md) · **中文**

机器词汇的词典——读者在它的区文件、终端行与契约中可能遇见的每一个词。原则：只要读者可能不懂一个词，它就在这里得到解释，用平实的语言，配一个例子或一个类比；`→` 指向本词典内的相关词条。机器自己的封闭词汇很小——八条法则的 id、六种结果、行状态（绿、红、过期）、流的行号（D1、D2、……）——下文其余一切解释的是这个词汇以及紧邻它的世界。

A

**接受（accept）**——机器对通过了每一条规则的文档所做的事：其规范字节与合并后的行为落进 → 对象存储、提交记录落进一个新日志纪元、机器亲自取走流的未入志言语、站立态移动、提交槽被吞掉。→ 拒绝 的反面。接受活在 `state.md` 的计数器里；终端行点的是下一步、从不是仪式。

**AGENTS 块**——机器的发现钩子：工作根 `AGENTS.md` 内一个带标记的块，以 `<!-- punchtape -->` 与 `<!-- /punchtape -->` 为界，每次运行被完整地确保。内容相同则什么都不碰；内容变了则自我替换；没有标记的外来文件在末尾获得该块。标记之外的字节永不被触碰；孤零零一个标记、或一对次序颠倒的标记，是机器响亮拒绝的手损。类比：图书馆藏书票——贴在封皮内侧，书页不属于图书管理员。→ 工作树。

**回答（answer）**——六种 → 结果之一：流的一行提出问题，回答的话就乘在 intent 本身（`text`）上。回答 intent 为该次运行锁住树：回答不被允许移动项目。→ 树锁。

**参数拒绝**——二进制对除单独 `--version` 之外任何带参数启动回答的唯一一行：拒绝点名法则（调用不取参数），并且就是那次启动的全部动作——状态不被触碰、退出 1。→ 调用。

**提问（ask）**——六种 → 结果之一：流的一行是对人类的开放问题、由一条 awaiting → 命令承载。awaiting 命令扣住裁决，直到一条更晚的人类行——得到自己的结果——关闭它、由决定性笔记点名。没有任何东西默认自行关闭；人类的沉默是一次诚实的停顿。

**Awaiting 命令**——处于 `awaiting` 状态的 → 命令：问题摆在人类面前、裁决等待。它只凭一条更晚的人类行关闭——该行被承载者占据、由决定性笔记引用；在那之前它扣住每一份裁决。另一种状态是 → deferred。

B

**行为（behavior）**——一个命名的可见行为单元：一个 id（`[a-z0-9-]` 段以 `/` 相连，比如 `tool/build`）、一行名字、作者的 → 散文、它的 → claims、可选的 → covers、以及至少一条 → row——其中一条必须被 → 钉住。id 是合并键：重复 id 的提交替换行为之头并合并其 rows。带 rows 而无 claims 的行为每次运行重跑——诚实地永远 → 过期。

**诞生（birth）**——创建实例的动作：对日志目录的一次原子 `mkdir`（并行运行中恰好一个赢家——输家作为普通一遍继续）、诞生记录（创建机器的版本）、对流的初始行的创世链环、以及由法则源写下的区的站立文件。没有任何别的东西会创建实例，且只有流的第一条非空行触发它。类比：在全新带子上打出第一孔。→ 实例、→ 流。

**构建（build）**——语料可选的已声明命令。它站立时，在每次启动上第一运行、先于任何 row、按与 row 相同的执行法。非零退出、超过 → 期限挂死、或从未启动的构建对整次运行为红：每条 row 被冻结——什么都不执行、除了构建自己的入志事实之外什么都不动。在文档中声明构建会替换站立的那条；缺席字段保留它。已声明构建的产物是工作——它们可以合法地移动树。→ 运行、→ 红构建冻结。

C

**调用**——机器的全部接口：`punchtape`、零参数、在工作根或其下任何位置。终端一行之外的一切回答都是 → 区的文件。→ 终端行、→ 退出码。

**Candor**——`law:candor`、响亮记录的法则：工作所跳过、许可或搁置的一切都不得默默通过。带原因与引用的响亮豁免；点名下令之行与被换之物的 mandate；带真实状态的命令、带原因的延期；引用可解析的笔记；处处非空的 prose——每个标记都是人类可以掂量的。引用 candor 的拒绝点名安静的洞。→ Mandate、→ 响亮豁免、→ 笔记、→ 法则 id。

**法则源（canon）**——机器作为法则印刷的一切的唯一内嵌源：英文契约（基底与尺）、俄文与中文镜像（给人的数据）、文档模板、带自己镜像的参考页、示例、法则映射、以及环境规则。区的契约、模板与参考在诞生时由它生成、变化时刷新；一个会对机器撒谎的示例让构建失败。→ 契约、→ 法则映射、→ 参考。

**规范字节**——一份文档的唯一官方写法：严格解码进模型、然后规范 marshal（两空格缩进、排序的映射键、按声明序的字段、保留的命令作者写法）。同一内容的两种写法是同一内容——机器只比较、只入志规范字节。例：重新缩进的 `inbox.yaml` 与原件是同一份提交。

**承载者（carrier）**——承载一个已声明结果的东西：回答承载其文本、执行承载其命令；工作与描述骑在一条行载该行的要求上；标记骑在其上的标记条目；提问骑同一文档的一条 awaiting 命令。承载者必须站在声明该结果的同一份提交里；移除承载者重新打开其行。→ Intent、→ 结果、→ 未分解行。

**链（chain）**——→ 流的过去的 sha256 脊柱：每条 demand-append 记录携带前链字节与新行相接后的哈希。每次运行按当前字节由创世重算整条链；一个不复现的链环是 → 区损伤、运行永不开始。过去不可变；尾巴开放。

**Claim（声明）**——行为所立足的树的行区间：`path/file.go:12-48`、相对根、first ≤ last。一个区间点名一个行为——已被持有的 claim 在其第二持有者处被拒。被 claim 各行的字节供养每个 → 证明内该行为的 claims 摘要；claim 内的改动使该行为的 rows 过期。覆盖住在被 claim 的行里、从不在 glob 里。

**干净环境**——机器每条命令所见的基础：恰是法则源声明的名字——`PATH` 与 `HOME`——取自运行机器的 shell，加上区的 → 钉、别无其他。实际传递的集合、连同机器版本、架构与内核版本，构成 → 环境哈希。

**完成动作**——签收：携带恰好 `done: true`、别无一物的 `inbox.yaml`。不是文档——通往 → 裁决的光秃而刻意的门。运行继续其普通步骤，由裁决步骤决定：每门皆绿——记录一份裁决；差任何东西——报告点名空洞。按自己的入志事实计数、与提交分开。→ 运行、→ done。

**契约（contract）**——机器作为一份文本的全部法则（区里的 `contract.md`、来自法则源），在 → 初次接触时整页打印到终端、并在区尚未诞生时同样整页打印。八条带 id 的法则——`law:demand`（流、其编号、结果、以及不在安静 intents 下移动的树）、`law:document`（唯一的格式及其合并法则）、`law:paths`（仅相对根路径）、`law:claims`（行区间覆盖与宇宙）、`law:proof`（钉住的字节、一个 run 一个行为、过期）、`law:candor`（响亮的标记、mandate、命令）、`law:done`（完成动作与裁决的门禁）、`law:your-tree`（执行环境）——外加循环、区文件与调用。英文文本为准；镜像携带同一法则集。

**语料（corpus）**——站立文档：每次被接受提交之后所站立的行为、注册表与构建命令。其规范字节以 `corpus.yaml`（生成的镜像、每次运行被治愈）存在、也在裁决的签名里。→ 语料版本。

**语料版本**——被接受提交的计数器：每次接受加一。裁决记录它被宣告其上的版本；`state.md` 的裁决行两者都点名，而下一条指令区分「裁决站立于当前版本」与「全绿、动作下一步」。→ 裁决。

**Covers**——行为的证明声明：该行为的 rows 所代表的要求 id 清单。cover 必须点名提交合并后仍然站立的要求；退役一个要求要求同一提交清掉它的每一个 cover。没有被任何 claim 行为的 covers 点名的站立要求是 → 孤儿要求、并扣住裁决。

D

**D 区间**——流行的唯一写法：`D<n>` 或 `D<a>..D<b>` 升序、逗号相连（`D1..D4, D9`）。编号按文件顺序点名流的非空行、每次运行由字节重新推导；要求的区间、标记的行、intents 的行、命令的 demand 都骑这套语法，机器也以它回写数字集合、连续段折叠（`D19, D23..D25`）。→ 流、→ 要求、→ 标记。

**期限（deadline）**——机器每条命令——每条 row、构建、每次执行——运行其下的天花板：到期整个进程组被杀、事实写作 `timed out after Ns`。默认 300 秒；区用一枚钉提高它——`PUNCHTAPE_ROW_TIMEOUT` 以整秒计。挂起杀手、绝非慢工作的裁判：机器限制一条命令可以挂多久、从不限制 agent 可以工作多久。→ 进程组、→ 红构建冻结、→ 钉。

**Deferred 命令**——带着自己的理由被搁置的 → 命令：问题连同需求、问题与理由永远显示在状态页上（`deferred orders:`）、但不扣住裁决。「人说了以后」的可见标记。→ awaiting 命令。

**描述（describe）**——六种 → 结果之一：该行请求对现状的描述、由一个行承载它的要求承载。与回答和执行一样，描述锁树：描述不被允许移动项目。→ 树锁。

**摘要（digest）**——机器的同一性单位：字节的 sha256、十六进制。同字节——同摘要；不同字节——以压倒性概率不同摘要。摘要调和机器的世界：行区间摘要、claims 摘要、证明、对象地址、树摘要、裁决的签名。面向人的写法切到前十二个字符——→ token。类比：指纹——不是手指、但足以点名它。→ 对象存储、→ 证明。

**Done**——`done: true`：两个词的完成动作、恰好如此、文档中别无一物。旗标旁的任何其他字段都被拒绝——光秃的动作才是要点。→ 完成动作。

**漂移（drift）**——树在站立裁决之下移动了的派生事实：某已认证行为的 claims 摘要不再等于裁决记录的指针。没有任何东西在观察——比较是入志事实与新鲜摘要之上的算术。状态页的裁决行说 `open (drift since run N)`——裁决之后第一个看到移动的 run——而漂移只被落在那个见证 run 之后的提交解决。裁决历史点名抓住每次漂移的 run 与治愈它的 run（其后第一条无红 row 的 run）。→ 裁决历史。

E

**环境哈希**——命令所见之物的指纹：机器版本、`GOOS/GOARCH`、内核版本、以及实际传递的排序 `NAME=value` 集（干净基加钉、含行期限钉）。它进入每个 → 证明：改变了命令所见之物的会话移动证明——rows 过期、永不假绿。

**纪元（epoch）**——日志流的一个编号文件（`journal/` 下的 `epoch-NNNNN.yaml`）：记录追加进活纪元、每条记录是行首 `---` 分隔符后的一个 YAML 文档。被接受的提交在其记录落盘前轮转流——每个提交的记录住在自己的纪元里；轮转绝不堆叠空文件。装载按编号顺序读每个纪元。→ 日志、→ 撕裂尾部。

**退出码**——调用唯一的二元答案：0——机器干活了（红 rows 是数据、不是错误）；1——调用没有发生（区损伤、装不上的日志、落不了地的机器自有写入、坏的钉或宇宙行、外来机器版本、行上的参数）。

**响亮豁免**——注册表的公开划除：一个真实的未覆盖行区间、标记着引用需求行或法则的原因、以及可解析的引用。标记不到任何未覆盖行的豁免被拒绝——什么都不标记的标记是噪声；空理由同样被拒。按区间合并；可用区间键退役。响亮豁免补全裁决的树=claims 算术。→ 空洞、→ 豁免提案。

**豁免提案**——`exclusions-proposal.yaml`：机器按自己的空洞算术起草的豁免清单：每个站立空洞作为带空 reason 与 refs 的现成区间——作者补理由、扔掉已 claim 的。没有站立空洞时提案离开。机器写路径；判断仍是你的。

**执行（execute）**——六种 → 结果之一：该行请求机器亲自运行一条命令、由 intent（`run`）承载。执行落在提交与 rows 之间——exit 与 stdout 入志（整体至 4096 字节、超出为对象存储的地址）、树为该次运行锁住。→ 执行事实。

**执行事实**——机器替 agent 执行的一次执行的入志记录：运行、应答的行、命令、exit、stdout 的摘要与 stdout 本身。最近执行显示在状态页与报告里。→ 执行。

**Expect**——row 对命令留下之物的要求：`rc`（精确退出码；缺席 = 0）、`out`（stdout：精确字节、或 `contains: ` 前缀后的子串）与 `files`（运行后读取的相对根路径、每文件同样的两种匹配写法）的任意混合。至少一个字段必须站立——空 expect 被拒。比较是纯粹的：任何地方都没有解释。→ 钉住的 row。

F

**初次接触**——起点之上没有 `.punchtape` 的启动：机器打印整份契约并以 0 退出、什么都不创建。终端的整页例外——文件通道尚不存在、法则本身就是回答。同一页也会为站着而无日志的区目录打印——无论它还装着什么。

**折叠（fold）**——由过去重建现在：全部日志记录从旧到新重放进 → 站立态——诞生定出身、提交动语料并应用承载者、运行定 row 事实、裁决站立、拒绝与完成计数。同样的记录永远折叠出同样的站立态。类比：从头重放一条穿孔带——带子是真相、机器的记忆是派生的。

G

**绿（green）**——row 的状态：它跑过、且每个期望都成立（破裂事实清单为空）。其 → 证明仍然站立的绿 row → 保持绿色——不重跑。语料在每条 row 都绿时为绿；只有带钉住证明的全绿语料能关闭裁决。

H

**空洞（holes）**——树的未覆盖行：没有被任何 → claim、也没有被任何响亮 → 豁免点名的行。`state.md` 拼写前十个文件、带计数与极大区间；`holes.md` 携带完整的无封顶账本；未覆盖行扣住下一份裁决。解析不出的区间写法、或超出文件自身行数的行、不 claim 任何东西——它点名的行仍是诚实的空洞。→ 树遍历、→ 豁免提案。

I

**Inbox（提交槽）**——`inbox.yaml`、区的唯一输入文件。它在意味着一份提交在等：一份待解码、校验并接受的文档——或 → 完成动作——或不改变任何东西的 → 拒绝（字节留着、作者修点名处再运行）。它不在是普通状态。进入机器的一切都经过这唯一的文件。

**实例（instance）**——机器的一个任务：一个工作根、它的区 `.punchtape`（日志、对象、面孔、槽）、以及根里的 AGENTS 块。诞生一次、永不死亡；真正的新任务是新鲜目录里的新流。一个区服务一台机器版本：由别的版本诞生的区被拒——归档并重开。→ 诞生、→ 区。

**Intent**——流之新行的申报 → 结果：哪些行、六种结果的哪一种、agent 的散文复述——以及该结果自己的承载者在同一份文档里。每条新行由迎接它的提交恰好一个 intent 申报；已携带结果的行永不重复申报。→ 回答、→ 执行、→ 描述、→ 工作、→ 标记、→ 提问。

J

**日志（journal）**——唯一的真相源：`journal/` 下只增的记录流；每个被接受的提交开一个新纪元。十种记录——birth、submission、demand-append、no-new-demands、run、execution-fact、tree-lock、verdict、refusal、completion——各恰携带自己的载荷、任何地方都没有壁钟：顺序是记录的位置、身份是它的字节。一段历史的日志在每台机器上字节相同。区的任何其他文件都是它的生成镜像。永不手改。→ 折叠、→ 站立态、→ 撕裂尾部。

K

**保持绿色（kept green）**——记录的证明等于当前证明的绿 row：该 row 不被执行、不被读取、不被触碰——它记录下的绿站立着。机器的全部经济：未变的输入分文不花。→ 证明、→ 过期。

**知识（knowledge）**——区的记忆文件 `knowledge.md`：每个被接受提交的每条笔记恰好一次（编号、带其 kind 与引用）、然后按原因分组的 → 教训条目。由日志生成；笔记本身从不被解读。

L

**法则 id**——契约的八条命名法则、每次拒绝的词汇：`law:demand`、`law:document`、`law:paths`、`law:claims`、`law:proof`、`law:candor`、`law:done`、`law:your-tree`。拒绝永远引用其一——被点名的规则与契约永远说着同一件事。→ 拒绝。

**法则映射**——法则源的平价表：每条校验规则绑到契约印刷的法则、每条被引用的法则绑到契约印刷的一条。被强制的皆被印刷；被印刷的皆被强制。

**教训（lesson）**——一次被修好的红、作为纯数据固定：原因类、row 键、破裂事实、该 row 前后的字节（由日志自己的 row 字节索引应答）、以及两次运行号。由运行记录自己写下——任何模型的 token 为零。教训按原因分组落在知识页上。例：一条 row 在 run 4 因 `exit: got 1, want 0` 变红、在 run 5 转绿——教训携带两条 rows 与两个号码。

M

**诞生时的机器**——诞生记录携带的机器版本：实例自己的出身事实、由状态页打印（`machine at birth:`）。由任何其他版本诞生的区在任何记录折叠之前被拒。版本也进入环境哈希、于是新机器诚实地作废旧证明。→ 诞生、→ 环境哈希。

**机器运行**——诞生之后调用的一次执行：链检查、提交步骤、执行、构建、指纹、过期 rows 的执行、入志、裁决、渲染。→ 运行号 只数改变了事实的运行（构建跑了、row 执行了、执行落了）；只度量并渲染的运行什么都不改。

**Mandate（授权）**——替换站立工作的许可：下令变更的流行、以及它许可替换的站立之物——一个行为 id 或要求 id、由这同一提交替换。没有 mandate 而替换或退役站立工作的提交被拒；点名本提交并不替换之物的 mandate 同样被拒。行证明存在、不证明意义——引用是给审计之眼的。→ candor。

**标记（marker，not-a-requirement）**——注册表的驳回：被声明为毫无要求的流行、附一个读者可以掂量的理由。行要么是要求、要么不是——绝不同时：要求行上的标记被拒。按行的折叠合并；可用 D 语法键退役。例：标题行被标记为「标题、非要求」。

**合并（merge）**——提交法则：行为按 id 合并（列出的头整体替换——name、prose、claims、covers——rows 按 → run 键合并）；要求按 id 同样合并；标记按其行、豁免按区间、命令按需求-问题对合并；退役先行；`remove` 退役站立键；缺席字段什么都不改；一次提交里的移除再加回是全新的。经济：提交次数永不影响价格——未变的 rows 不被重发。

**Mark（标记结果）**——六种 → 结果之一：该行毫无要求、由其上的 → 标记承载。标记按构造即是响亮的——一个理由、成文、永远在语料里。

N

**下一条指令**——机器唯一的祈使、终端行与 `state.md` 的 `next:` 行里同一段文字：拒绝说在 inbox 里修点名处；构建红说修构建；语料空说交第一份文档；无行为的注册表说交一个带钉住 row 的行为；每个裁决阻塞者说自己的指令；站立于当前语料版本的裁决说把 `state.md` 给人看；全绿说写 `done: true` 并运行以记录裁决。机器可站的每个状态恰有一条指令——绝无两种真相。

**No-new-demands**——没有新的人类言语到来的签名声明：签署时的流行数与签署的运行、入志在被接受提交旁。对确实到来的言语签下的签名永远留在日志里——防护为可见性而非门禁的唯一一点：状态页携带签名、而言语保持未入志、仍可申报。下一个 demand-append 清除站立的签名。

**笔记（note）**——文档携带的结构化自由文本：五种 kind（directive、decision、exclusion、lesson、work）之一、一个 text、以及必须可解析的引用——一条流行、一个站立的要求或行为、一个可解析的行区间、或契约印刷的一个法则 id。机器从不解读笔记；它携带并索引它。给人的通道、不是进入机器的通道。

O

**对象存储**——`journal/objects/` 下按内容寻址的存储：对象名是其字节的 sha256；文件是存储根下的 `<first two hex>/<remaining sixty-two>`。相同字节存一次——构造即去重；每次写入重读复核、每次读取核验其摘要。每份被接受文档的规范字节与每个合并后行为的规范字节住在这里、不可变。→ 摘要。

**命令（open order）**——摆在人类面前的一个问题：它所骑的流行、问题本身、及其状态——→ awaiting 或 → deferred。Awaiting 扣住裁决；deferred 带着自己的理由永远可见。按需求-问题对合并；命令的出生事实是机器自己的。→ 提问。

**孤儿要求**——没有被任何带 claims 的站立行为在其 covers 里点名的站立要求。扣住裁决（`the requirements … stand uncovered by any behavior's covers`）。→ covers。

**结果（outcome）**——流行所要求之物的六种写法：`answer`、`execute`、`describe`、`work`、`mark`、`ask`——协议自己的词汇、在行到来之时由 → intent 申报。回答与执行携带自己（text、run）；其余四种骑同一文档的注册表。没有结果的行是 → 未分解行。

P

**钉（pins）**——区的环境声明：`env` 文件、一行一条 `KEY=VALUE`、键 `[A-Za-z_][A-Za-z0-9_]*`、一名一钉、无 `export`、无引号、无绝对路径（钉随树旅行）。注释与空行通行、容忍尾随回车。任何其他形状的行是点名文件、行与法则的响亮拒绝。钉按名胜过干净基；每枚钉都进入环境哈希。例：`TOOLS=tools/bin`——值可以是相对路径、绝不能是绝对的。

**钉住的 row**——其 expect 钉住精确字节的 row：一个非空、非 `contains: ` 前缀的 `out`、或每个值都钉住精确字节的 `files`。钉住的 row 是行为的证明；其余一切都是评论。仅 `rc` 钉不住任何东西——绿色退出码只证明命令结束了。每个行为携带至少一条钉住的 row、否则提交被拒。

**进程组**——启动纪律：机器的每条命令在自己的组里跑、它留下的一切活物（服务器、worker、shell 抬起的一切）随组被杀——向组与进程发死亡信号、然后等待实际死亡的有界等待。row 的遗留物绝不比 row 活得久。

**证明（proof）**——row 的指纹：row 规范字节、其行为的 claims 摘要、与 → 环境哈希的 sha256。记录的证明等于当前证明期间、该 row → 保持绿色；三者任何一个移动都使它 → 过期。类比：盖在 row、其输入与其处境之上的火漆印——破其一、印即破。

**散文（prose）**——作者拥有的话：要求对需求的人类语言展开、行为关于用户得到什么的故事、intent 对行的复述。强制且非空；逐字搬上 spec 页与 trace。机器查存在、从不查质量——阅读属于人类。

R

**红（red）**——row 的状态：它跑过、且至少一个期望破裂（按实测入志的破裂事实就是原因）。红 rows 在报告里按原因分组。跳过法则色盲：证明仍站立的站立红恰在其 → 证明移动时重跑——与让绿 row 保持绿的同一条法则；但站立的红绝不为完成通过、因为 → 裁决读事实的状态、从不只读证明。站立裁决下的红 rows 是 → 漂移。

**红构建冻结**——失败的构建让一切停摆的法则：本次运行没有任何 row 执行、没有任何 row 事实移动；运行记录只携带构建的事实、下一条指令说 `build red`。同一次运行携带的提交仍然落地——语料移动、rows 等待。

**参考（reference）**——`reference.md`、区自己的手册页：一页之上机器的每一扇门——调用、流、文档、intents、注册表、合并、执行、宇宙、裁决、面孔、钉、损伤、常量——写在法则源里、诞生时生成进区、法则源一变就刷新。完整知识始终在手边、agent 从不需猜。→ 法则源、→ 契约、→ 模板。

**拒绝（refusal）**——机器对破裂提交的回答：一条破裂规则一行——确切的字段、→ 法则 id、度量的 fact。提交的字节什么都不写；拒绝本身作为机器自己的事实入志、并在 `state.md` 上计数；文档留在 `inbox.yaml`、作者修点名处再运行。例：`behaviors[0].rows[1].expect: the expect is empty — name rc, out or files (law:document)`。→ 校验。

**注册表**——语料对言语的账目：要求（各带其流行区间）、标记、响亮豁免与开放命令。按提交法则合并；整体摘要进裁决的 → 注册表摘要。

**注册表摘要**——要求、标记、豁免与命令一起的规范字节的 sha256——言语的全部账目、以一枚印封存、由裁决记录携带。

**Remove**——文档的退役清单、五种写法：一个要求 id、一个行为 id、一个 `D<n>` 的标记或命令键、一个 `path:first-last` 的豁免键。每个键必须站立；退役在合并中最先走；退役一个要求重新打开它的行、并要求同一提交重新悬挂它的每一个 cover；行为连同其 rows 整体退役、在 → mandate 之下。

**报告**——`report.md`：最近一次改变事实事件的全景——对一次运行：构建行、执行、绿色计数、每条红 row 按其破裂原因分组、外加完成动作说话时的裁决注记；对一次拒绝：每拒绝一行、加修复指针。移动时整页重写；什么都没改、什么都没关的运行让前一份报告站着。→ 拒绝、→ 裁决、→ 面孔。

**要求（requirement）**——一个被具体化的需求：一个 id（`R` 加字母数字点、比如 `R1`）、它占据的流行（D 区间）、散文展开、可选的 `refines` 父。按 id 合并；只经显式 `remove` 退役——它同时清掉它的每个 cover。当每行都携带其结果与承载者时、流被完整分解。

**Row**——行为内部一条可执行的检查：一条命令（`run`——shell 行或 argv 表）与它的 → expect。命令的规范字节是该 row 的 → run 键、也是其 → 证明的一部分；row 在行为中的位置是它的日志键（`<behavior id>/<index>`）。rows 是行为证明的全部。

**Run 键**——命令的规范字节、row 的合并键：一个站立的被提交 run 整体原位替换其 row；新 run 追加；未列出的 rows 站立。重写的命令是一条新 run——站立的那条站着；一条命令证明一个行为。例：`./tool src out` 与 `["./tool", "src", "out"]` 是同一 run 的两种写法。

**运行号**——改变事实的运行的计数器。终端行的 `run <N>`、报告、状态、trace、知识、spec 的页眉全部点名同一个数。拒绝不花运行号——它由自己的计数器数。

S

**签名（裁决的）**——语料规范字节、加上按语料自身顺序每个行为 `\0 id \0 claims digest` 的 sha256：规格与它被宣告其上的确切树态、在一个摘要里。在状态页与裁决历史里以短形（十二字符）显示。

**Spec 树**——面孔目录 `spec/`：`index.md` 加每个活行为一小页——id 与名字、运行号、Story、它应答的 Demands、带逐区间摘要的 Claims、带证明站立的 Rows、Verify 命令。退役行为的页面被删除——该树是站立语料的镜像、别无其他。

**过期（stale）**——row 的状态：其 → 证明移动了（其字节、其行为 claim 的行、或环境）——或它从未跑过——或其行为不声明 claims。过期的 rows 在下次运行执行；指令数它们（`N row(s) stale — run again to execute them`）。

**站立态**——由日志经 → 折叠重建的现在：出生事实、链、语料版本与构建、注册表、行为及其顺序、row 事实与 row 字节索引、行结果与承载者、运行号、裁决、计数、教训、树锁 hold。机器的一切决定都按站立态做——而站立态永远可仅由记录推导。

**状态页**——`state.md`：一页上的站立态——言语账目与未分解行、队列、签名、语料版本、计数器、诞生时的机器、带漂移标记与历史及 deferred 命令的裁决、每行为一行、未覆盖与豁免行、知识计数、以及 `next:`——与终端行相同的文字。→ 站立态、→ 面孔。

**流（stream）**——人类言语本身：`demands.md`、永远开放、每条非空的去空白行按文件顺序编号 D1..Dn。言语由 agent 的手进入文件；机器在下一次提交亲自取走它们（从不重打进文档）、用 → 链封锁过去、并为每次提交的言语或其 → no-new-demands 签名入志。被碰的过往行是 → 区损伤。

**提交（submissions）**——被接受的文档、在 `state.md` 上与被拒及完成并列计数——三种独立的经济：槽收下的文档、它拒绝的提交、完成工作的完成动作。

T

**模板（template）**——`template.yaml`、诞生时由法则源生成并随之刷新：带教学注释的文档形状——每个字段、YAML 烹饪四规则、remove 写法。复制、编辑、作为 `inbox.yaml` 提交。解码通过但破坏规则的文档仍被拒——模板教形状、校验执法。

**终端行**——成功运行时调用的一行输出：`punchtape: run <N> — <instruction>`。指令点名要动的文件、并与 `state.md` 的 `next:` 行是同一段文字。例外：初次接触打印整份契约；未诞生的区打印它的一行指令；无法发生的调用改答它的单行错误——退出 1。机器要说的其余一切住在区的文件里。

**Token（令牌）**——→ 摘要 的人类可读短写法：它的前十二个 hex 字符。状态页上的裁决签名与 row 证明、spec 页上的行为 token、trace 上的 claims token——都是 token；眼睛比较它们、机器比较完整摘要。token 为阅读而生；完整摘要才是同一性。→ 摘要。

**撕裂尾部**——写到一半被切断的日志记录（崩溃、断电）。它不会弄瞎机器：完整的记录装载、撕裂的字节隔离进旁车（`<epoch>.torn`）、纪元文件由完整记录逐字节重建。末位之外解析不出的块是手损——诚实的错误。→ 纪元。

**Trace（踪迹）**——`trace.md`：流的橱窗——每一行带自己的文本、申报的结果、复述、及其下的承载者（要求、带 claims 与证明 rows 的行为、标记、回答、最近的执行、命令）。什么都不判；一切都为眼睛摆好。为人类的审计一瞥而建的一页。

**树摘要**——工作树自己的指纹：每个计入文件的排序 `path\0digest` 行的 sha256——二进制以其字节计入、区与版本控制簿记按名排除。在锁住的提交前后各测一次：移动了的摘要是入志的 → 树锁事实。

**树锁**——对付安静移动的 hold：一份 intents 站立、无一为 `work`（且无站立或声明的构建——构建的产物是合法工作）的提交为其运行锁住树。摘要前后各测一次；移动被入志并扣住裁决、直到字节复原或该改动作为申报的工作提交。work intent 解除站立的 hold 且不武装新的。→ 回答、→ 执行、→ 描述。

**树遍历**——机器看工作树的唯一方式：一次有序遍历、按名跳过区（`.punchtape`）与版本控制簿记目录（`.git`、`.hg`、`.svn`）无论它们站在哪、按声明的 → 宇宙过滤、数每个内部文件的行并摘要其字节、并只按名数外部文件——响亮地、从不读。带 NUL 字节、空、或不可读的文件整体站在覆盖宇宙之外、带点名的原因。机器从不把树的内容当代码读——只当作摘要的字节与执行的命令。→ 遍历缓存。

U

**未覆盖行**——树的空洞：没有被 claim、也没有被响亮豁免点名的行。逐文件点名、带计数与极大区间——状态页上前十个文件、完整账本在 `holes.md`、草稿在豁免提案里。未覆盖行扣住下一份裁决；站立的裁决可以 visibly 地活在它们之上（`standing over N uncovered lines`）。→ 空洞。

**宇宙（universe）**——区对什么算数的可选声明：`.punchtape/universe`、一行一条相对根路径、`#` 为注释、不声明即整棵树。点名不到树中任何文件的根被响亮拒绝——绝不是悄悄的覆盖丢失。宇宙之外的文件在状态页上计数、从不被审判。→ 树遍历。

**未分解行**——没有申报 → 结果、或没有其申报结果之站立承载者的流行：「no outcome」「work pending」「mark pending」。在状态页与 trace 上带原因点名；未分解行扣住裁决。移除承载者重新打开其行。

V

**校验（validation）**——文档在被接受之前通过的完整规则集：严格解码与装甲走查；id 的字母表与唯一性；对 流宇宙的 D 语法；同一口气的结果承载者；是树所承载之行区间的 claims、一区间一行为；带名字、站立 covers、带期望的 rows、至少一条钉住的 row、rows 内及跨行为唯一的 runs 的行为；要求行之外的标记；带引用原因、盖真洞的豁免；骑站立行、带真实状态的命令；替换站立工作的 mandate；引用可解析的笔记；点名站立之物的 remove；恰为裸文的 done 文档——外加机器自己的门禁：悬空 covers、claim 重复、ask 关闭法。每次拒绝点名字段、fact 与法则 id。→ 拒绝。

**裁决（verdict）**——机器对完成的宣告、只在 → 完成动作上、且只在每道门站立时记录：语料非空；每条 row 在当前指纹下绿；每个行为由一条绿色 → 钉住 row 证明；流完整分解；每个要求被覆盖；树等于其 claims 加响亮豁免；没有等人的命令；漂移被点名；没有树锁 hold。记录携带编号、语料版本、→ 签名、→ 注册表摘要、每个行为的 claims 指针与关闭的运行；旁边落一条完成记录。只增——新的从不改写旧的。差任何东西都是 `not yet` 加报告中每类空洞一行、按所有面孔消费的同一顺序。

**裁决历史**——状态页的派生编年史：每条记录的裁决（运行、编号、版本、短签名）；每次 → 漂移（站立裁决下带红 rows 的运行、带 row 键）；每次痊愈（其后第一条无红 row 的运行）。最近十个事件、省略号数其余。日志不携带的、历史不说。

**版本旗标**——`punchtape --version`、恰好这个写法、单独一行：打印 `punchtape <version>` 并在任何状态之前以 0 退出——唯一的人类便利；契约从不提它。→ 调用、→ 退出码。

**面孔（views）**——区的生成文件：`state.md`、`report.md`、`trace.md`、`knowledge.md`、`holes.md`、豁免提案、spec 树、`corpus.yaml`。日志的镜像——内容变化时整页重写、不变时绝不动；落不了地的面孔是响亮的失败（过期的脸是谎）。

W

**遍历缓存**——`cache/tree`：树遍历的已验证加速器、一文件一记录——路径、大小、mtime、行数、摘要。大小与 mtime 与缓存所见一致的文件复用缓存的事实而非其字节；证明从不问缓存——claim 的行总是直接读取。运行结束时写一次、只在遍历动过它时。删掉它、下一次运行重算同样的数——加速器、永非真相源。→ 树遍历。

**工作（work）**——六种 → 结果之一：该行订购对项目的更改、由一个行承载它的要求承载。work intent 是移动树的合法方式——它解除站立的树锁 hold 且不武装新的。→ 树锁。

**工作根 / 工作树**——携带区的目录（调用在其起点或之上找到它）与其旁的一切。树是 agent 的领地：机器遍历它、摘要它、在其中执行命令——而从不把它的内容当代码读。

Z

**区（zone）**——`.punchtape/`、机器唯一拥有的目录：教学页（`contract.md`、`template.yaml`、`reference.md`）、槽（`demands.md`、`inbox.yaml`、`env`、`universe`）、生成的站立文件（`corpus.yaml`、`state.md`、`report.md`、`trace.md`、`knowledge.md`、`holes.md`、`exclusions-proposal.yaml`、`spec/`）、带其对象的日志、以及机器自己的 `cache/` 与 `tmp/`。永不手改；一条记录站在它外面——工作根里的 → AGENTS 块。→ 区损伤。

**区损伤**——机器最响亮的拒绝：过去断了、或这个区不归这台机器读。流被碰的过往行、已诞生实例上被截短或删除的 `demands.md`、一条不复现的日志记录、由别的机器版本诞生的区、损坏的 AGENTS 标记——一行、退出 1、运行永不开始。日志与链持有过去；手损被点名、从不用猜测绕过。
