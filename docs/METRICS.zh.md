## 0. 出处、基准、价格、诚实

  `campaigns/case-0/docs/METRICS-0.2.0.md`（保存于 v0.3.0 标签），

- **0.3.0（2026年10月）**——五波实地系列测试的登记簿：
  `campaigns/case-0/docs/METRICS-0.3.0.md`（保存于 v0.3.0 标签）；

  每个数字从五次波的 `usage.tsv` 与裁判页机械汇集，再由独立校验器
  重算：**0 处差异**；下文 §3 完整载有该纪元的数字。
- **token 基准。**`in+out` 处处是工作基准；`total` = in+out +
  缓存读，在 0.3.0 与 0.4.0 登记簿中并列印出。任何纪元的裁决都
  不随基准改变。
- **时间基准因纪元而异，绝不混用。**0.2.0 打印执行手的完整墙钟
  （全部平台段）；0.3.0 打印执行手与操作者的墙钟秒数；0.4.0 打印
  纯请求时间之和（`work_ms`）——0.4.0 各波墙钟不可跨波比较（各波
  的 live-subagent 上限不同），仅作日历背景给出。
- **每个纪元的每个实验中操作者都是 LLM。**模型记录：
  **0.2.0——每个角色都是 GLM-5.3 Max**（执行手、操作者、裁判、

  0.3.0/0.4.0 的台账将模型固定为「GLM-5.3」；档位即该记录。High
  档的价格未在那些战役中记录——因此 0.3.0/0.4.0 的经济学以 token
  和时间立身，§4 中它们的每一个美元数字都是参数化的，并如此
  标注。
- **月份纪法。**0.4.0 材料按开发纪法计时——自 0.4.0 开发起算的
  月数；按该纪法 M 系列是 2026 年 10 月（纪元登记簿自己的波根保留
  其平台时间戳）。
- **诚实标注**（登记簿的现行法）：测得的数字就是测得的数字；带
  标注的估算自陈其身份；任何外推之物不会默默过关。下文用到的唯一
  外推——真人锚 ×1.2–2.0 于 AI 操作者的墙钟——是研究论文附录 E
  的修正，在此连同其标注一并沿用。
- **此处测量的各代是过去的发布。**机器此后被重构建、越过了
  0.4.0：发布的 0.5.0 版是同一倒置的又一次重构建（需求流、六种
  结果、行区间 claims、光秃的 `done: true` 动作），该重构建的

## 1. 0.2.0 指标（2026年9月）

S 波——20 个非 brim 任务 × 3 执行手（solo；top+machine；
flash+machine），每单元均值（纪元登记簿的 §7）：

| 指标 | solo | top+machine | flash+machine |
|---|---|---|---|
| 执行手 \$（缓存感知，均值） | 4.88 | 1.16 | 0.31 |
| 每单元操作者 \$ | 1.19 | 0.02 | 0.01 |
| **全路径 \$（执行手+操作者）** | **6.07** | **1.18** | **0.32** |
| 执行手时间，秒（完整墙钟，均值） | 1556 | 1131 | 2258 |
| 执行手生命 token | 5.9M | 2.8M | 4.5M |
| 缓存拆分覆盖率 | 58% | 99% | 89% |
| 套件 ×2 绿 / 交付物 5/5 | 20/20, 20/20 | 20/20, 20/20 | 20/20, 20/20 |
| 裁决 | 20/20 ACCEPTED | 20/20 READY | 20/20 READY |
| 对照 top 基准通过的裁判行 | 87/336 (26%) | （基准） | 105/336 (31%) |
| 宿主边界红线 | 0 | 0 | 3 |

**解读，逐条事实。**

- **全路径：5.1× 与 19×（美元，实测）。**solo 单元均价 \$6.07，
  其中 \$1.19 是客户的验证工作（阅读、搭环境、验收轮次）。走机器，
  同一任务花 \$1.18（top）或 \$0.32（flash）。机器的经济不是
  token 把戏：它接管了验证本身（每条检查在干净目录中跑两遍，字节
  精确），买家不再为重复阅读付费。
- **操作者列：1.19 美元对 0.02 美元。**机器执行手的操作者在
  S 波 40 个单元中触发了 7 次（波 1 中 10 次里 0 次），每次触发
  只花几美分；solo 的操作者每个单元都触发。这是 §3 中主导模式的
  首次实测现身：机器路径把验证者从循环中拿掉，solo 路径做不到。
- **token：5.9M 对 2.8M；缓存 58% 对 99%。**没有一台已经做过
  验证的机器，agent 就反复阅读、反复探测自己的产品；有了它，迭代留在
  同一个上下文里。质量没有为此付账：盲度量者看不出各执行手产品
  之间的差异（套件 ×2 绿、交付物处处 5/5）。
- **flash 的代价。**最便宜的执行手（\$0.32）背了该波全部三次宿主
  边界违规：更弱的模型更常弄坏环境机制——便宜，但附带监督警示。
- **机器没有买到什么。**「声称 ≠ 事实」诸类别仍只能由人类等价
  操作者或裁判抓住：solo 的 20 次验收中 13 次带着真实发现进入
  第二轮；每个交叉裁定的产品恰在这些类别上不过裁判行。机器让它
  自己路径上的验证性阅读变得不必要；对别人的路径它不能取而代之。

- **G1——全路径——25 个任务中 23 个归机器。**即便在 quire，那个

- **操作者倍数：token 17.6×，墙钟 9.2×。**每单元 solo 操作者

  战役的设计是两个阵营每单元都跑一个操作者（机器每单元一次微
  决策）——因此此处的倍数是 0.2.0 模式的*折价*形态（其中机器
  操作者仅在 40 个单元中的 7 个触发）。
- **G2——只看执行手——取决于任务：16/4/5。**九月的再探测机制

  例外：Σ-执行手 0.87，整个系列测试唯一低于平价的波。登记簿记录
  了这一倒挂；其原因仍是开放工作。
- **裁判维持分离。**solo 产品对照机器执行手自己的表，字节严格：
  21/96 … 42/103——每个波的表都为 solo 留着一片红。计数有记录；
  红行的类别解读不在本界面重新推导。
- **未 ×2 的单元。**盲双重复放在三个机器单元和一个 solo 单元中
  拒绝了不可重复的字节——度量程序的诚实边界；裁决未受影响。

agent 都是 GLM-5.3 High，注入墙自 M-brim 起启用。时间为纯请求
工作（`work_ms`）；token 除特别指名外均为 in+out。

按题域分的阵营（执行手 + 其操作者）：

更便宜的技术栈（×1.11），cpp 的 token 平价精确到 115M 中的 12K
（×1.00），机器时间 ×1.15，go 与 python 稳定为机器 ×1.05 /
×1.26–1.32。整个系列：1063.44M token in+out，纯工作 ≈47 h 17 m，

**解读，逐条事实。**

- **阵营裁决：两种 token 基准下 ×1.06，时间上 ×1.24。**无仪式
  重造之后，机器阵营再次是更便宜的路径——而且是时间优势达到如此
  大的唯一纪元：0.2.0 买到的是美元（5.1×），0.3.0 买到的是 token
  （阵营合计 ×1.66），0.4.0 首先买*滴答*（×1.24），其次才是
  token（×1.06）。
- **优势是两个科目，不是一个。**机器执行手的 token 更*重*
  （443.71M 对 403.56M，solo ×1.10），时间更*轻*（×1.07）；机器
  操作者两者皆轻（×24.0、×5.5）。阵营的胜利由操作者科目加执行手
  时间科目组装而成——而操作者科目是唯一在系列每个题域与技术栈
  上都无条件的科目。
- **G2 平价是这次重造的签名。**0.2.0 中循环的执行手花 2.8M，
  solo 是 5.9M（机器吸收了验证）；0.3.0 中执行手仍随任务分裂，
  带一道仪式溢价；0.4.0 中单看执行手已是平价（11/12/2，中位数
  16.42/15.19M）。工作本身如今在两个阵营花销相同——只是货币
  不同：机器用 token 换滴答。系列的全部四次 G1 分裂恰好是同一类
  ——token 归 solo，时间归机器——这就是那笔交易，逐单元可见。
- **2 对 32 次 DEMAND。**solo 操作者在 25 个任务中被迫 32 次
  *构造*证明（规格 → 场景 → 绿运行 → 覆盖要求）；机器阵营的
  2 次是实质例外（一次未证明的停止、一次未证明的中断）。在机器
  阵营，验证已经活在裁决之内——50/50 单元以现行签署的全账目裁决
  关闭。
- **质量不区分阵营；经济学区分。**两阵营 1720 个行评分均 0 缺失；
  13 对 8 的「部分」差异是对拒绝与停止的边缘打磨，在噪声之内。
  裁定机器单元的花销略低（69.39M 对 72.30M，×1.04）——渲染出
  的区文读起来比生裸的 solo 树更重。
- **技术栈与题域。**机器最好的情形是无构建的解释型栈（js：机器
  每过一次自带一个短循环）；最差的是长编译（rust：机器每过一次
  都付一遍构建，时间优势缩到 ×1.12）。按题域，conduit 最合机器
  （一部计数器与路由之法整个落进语料，4/5，×1.45/×1.46），brim
  最差（一台紧凑的图像传送带 solo 组装更便宜，2/3 归 solo）。胜利
  更多取决于任务的形状，而非技术栈。
- **解读的边界。**整个系列固定一个二进制与一个模型：内部效度
  完整，外部效度（其他模型）不予主张。live-subagent 上限因波而异
  ——各波墙钟不做比较，只比较工作总量。中位数紧靠均值：没有
  一个单元独扛总量。

## 4. 操作者是 LLM：真人重归一化

### 4.1. 记录及其重要性

上文的每个实验里，「操作者」——负责验收、验证、回答要求的一方
——本身就是语言模型：**0.2.0 纪元为 GLM-5.3 Max，0.3.0 与
0.4.0 为 GLM-5.3 High**（模型记录；台账固定为「GLM-5.3」）。
两个后果：

1. §1 中的每一块操作者美元都是 *AI 操作者*美元，按 2026-09-03
   的 Max 价格计；§2–§3 中的每一秒操作者时间都是 *AI 的*墙钟。
2. 对真人，同样的工作在时间上严格更贵：人按阅读速度读、手工重跑
   （AI 几秒内重读整个上下文并发射自己的探针）；人背负环境搭建、
   疲劳与上下文切换，这些不在 AI 的墙钟里；而人的回答是异步的
   ——记录在案的等待是暂停的机器一侧，从来不是人的日历。

研究论文的附录 E 在 0.2.0 数据上锚定了该修正：solo 验收操作者的
AI 墙钟平均每任务 530 s（8.8 分钟）；同类工作的真人锚是每任务
10–18 分钟——**AI 墙钟的 ×1.2–2.0**（出自八月收尾估算的带标注
估计，不是这些波的测量）。该锚在下文原样沿用，逐纪元应用于该
纪元自己实测的操作者墙钟。

### 4.2. 操作者科目，逐纪元实测

| 纪元 | solo 操作者（实测） | 机器操作者（实测） | 比值 |
|---|---|---|---|
| 0.2.0，S 波 | 每单元 \$1.19；平均墙钟 530 s；**每个**单元都触发（13/20 第二轮） | 每单元 \$0.02；40 个单元中 7 个触发 | 美元 ×60；触发 40:7 |
| 0.3.0 系列测试 | 每 25 单元 42.71M in+out / 11107.7 s（每单元 444 s、1.71M） | 每 25 单元 2.43M / 1205 s（每单元 48 s、0.10M） | token ×17.6，时间 ×9.2 |
| 0.4.0 M 系列 | 每 25 单元 71.51M / 13132 s（每单元 525 s、2.86M）；**32 次 DEMAND** | 每 25 单元 2.98M / 2372 s（每单元 95 s、0.12M）；**2 次 DEMAND** | token ×24.0，时间 ×5.5 |

平白地读：三代全部实验里，机器阵营的验证者花销从几美分到可忽略，
且只在例外时触发；solo 阵营的验证者是一个常设科目——而且是整个
比较中唯一在任何纪元的任何波、题域或技术栈中都不变号的科目。

### 4.3. 重归一化为真人操作者

把一个人换进操作者之位；两个阵营的执行者都仍是模型（这才是现实
的部署：模型写，人验收）。执行手不受替换影响；移动的只有操作者
科目。把 ×1.2–2.0 的锚应用到 0.4.0 M 系列的墙钟上：

| 每 25 任务系列的操作者成本 | solo 阵营 | 机器阵营（同量） | 机器阵营（仅实质） |
|---|---|---|---|
| AI 墙钟（实测） | 13132 s = 3.65 h | 2372 s = 0.66 h | — |
| 人工墙钟（×1.2–2.0，带标注） | **4.4–7.3 h** | 0.8–1.3 h | 2 个 DEMAND 回答 ≈ 0.2–0.5 h |
| 按 \$30/h | \$132–219 | \$24–40 | \$6–15 |
| 按 \$50/h | \$219–365 | \$40–66 | \$10–25 |
| 按 \$100/h | \$438–730 | \$79–132 | \$19–50 |
| 按 \$200/h | \$877–1460 | \$158–263 | \$38–99 |

（「同量」按人的步速为同样的验证工作计价；「仅实质」只计机器阵营
真正需要人的部分——那两次例外回答；其余 23 个任务的验收由机器
自己的裁决以零人力承载。High 档的 token 价格未记录——故意不为
0.3.0/0.4.0 的 AI 操作者行编造任何美元数字。）

**节省及其引发的倒转。**按同量计，机器阵营每 25 个任务省下
**3.6–6.0 小时的验证劳动**（按费率表折合 \$110–1200）；按实质计，
它省下 **~4–7 小时——几乎是整个验证科目**。在 AI 操作者之下，
机器阵营以 token ×1.06 赢下系列——一个 token 价格变动就能抹掉的
差距。在真人之下，差距完全不依赖 token 价格：它是每个系列数小时
的熟练注意力，外加 AI 墙钟从不建模的日历——solo 阵营一个任务
一个任务地人工验收，把整波串行在操作者的可用性上，而实测系列在
≈29.6 h 的连续日历里跑完 25+25 个任务。0.2.0 论文的结论（「效应
的产物不是 token 价格，而是劳动转移」）因而是后来各纪元中*更强*
的主张：每一代都把同一个科目——验证者——更远地移出人的日程，
而无仪式的 0.4.0 机器最终把*执行手*也留在了平价，于是两阵营之间
剩余的全部差异，恰好是人必须身居其中的那个科目。

### 4.4. 本节的诚实标注

×1.2–2.0 的真人锚是带标注的估计（附录 E 的八月锚），不是这些
系列的测量；按费率的美元表是该锚上的参数化算术；模型档位记录
（Max / High）立于将模型固定为无档位「GLM-5.3」的台账之上；
DEMAND 计数出自各波日志；3.65 h 与 0.66 h 的 AI 墙钟是实测的
`work_ms` 之和。此处其余没有任何外推。
