# Глоссарий
[English](GLOSSARY.md) · **Русский** · [中文](GLOSSARY.zh.md)

Словарь машинной лексики — каждое слово, которое может встретиться
читателю её файлов зоны, её строк терминала и её контракта. Принцип:
если читатель может не понять слово, оно объясняется здесь, простым
языком, с примером или аналогией; `→` указывает на родственные термины
внутри этого словаря. Собственный замкнутый словарь машины мал — id
восьми законов, шесть исходов, стояния ряда (зелёный, красный,
устаревший), номера строк потока (D1, D2, …) — а всё остальное ниже
объясняет этот словарь и мир непосредственно вокруг него.

A

**Принятие (accept)** — то, что машина делает с документом, прошедшим
каждое правило: его канонические байты и слитые поведения ложатся в
→ хранилище объектов, запись подачи — в свежую эпоху журнала, машина
сама берёт незажурналированные слова потока, стоящее движется, слот
поглощается. Противоположность → отказу. Принятие живёт в счётчиках
`state.md`; строка терминала называет следующий шаг, а не церемонию.

**Блок AGENTS** — крючок обнаружения машины: помеченный блок в
`AGENTS.md` рабочего корня, ограниченный `<!-- punchtape -->` и
`<!-- /punchtape -->`, обеспечиваемый целиком на каждом прогоне.
Идентичное содержание ничего не трогает; изменившееся заменяет себя;
чужой файл без маркеров получает блок в конец. Байты вне маркеров
никогда не трогаются; одинокий маркер или перевёрнутая пара —
повреждение, от которого машина отказывается громко. Аналогия:
книжный ярлык библиотеки — вклеен под переплёт, страницы не
библиотекаря. → рабочее дерево.

**Ответ (answer)** — один из шести → исходов: строка потока задаёт
вопрос, и отвечающие слова несёт сам интент (`text`). Ответ-интент
запирает дерево на свой прогон: отвечать не разрешено двигать проект.
→ замок дерева.

**Отказ от аргументов** — единственная строка, которой бинарник отвечает
на любой запуск с аргументами, кроме единственного `--version`: отказ
называет закон (вызов не берёт аргументов) и есть всё действие этого
запуска — состояние не тронуто, выход 1. → вызов.

**Вопрос (ask)** — один из шести → исходов: строка потока есть открытый
вопрос человеку, носимый ждущим → приказом. Ждущий приказ держит
вердикт, пока позднейшая строка человека, получившая свой исход, не
закроет его — процитированная заметкой-решением. Ничто не закрывается
само по умолчанию; молчание человека — честная остановка.

**Ждущий приказ** — → приказ в состоянии `awaiting`: вопрос стоит перед
человеком, вердикт ждёт. Он закрывается только поверх позднейшей строки
человека — занятой носителем, процитированной заметкой-решением; до тех
пор держит каждый вердикт. Альтернативное состояние — → отложенный.

B

**Поведение** — одна именованная единица видимого поведения: id
(сегменты `[a-z0-9-]` через `/`, скажем `tool/build`), однострочное имя,
→ проза автора, его → клеймы, необязательные → covers и хотя бы один
→ ряд — один из которых обязан быть → пинованным. Id — ключ слияния:
подача, повторяющая id, заменяет голову поведения и сливает его ряды.
Поведение с рядами без клеймов перезапускается каждый прогон — честно
всегда → устаревшее.

**Рождение** — акт, создающий инстанс: один атомарный `mkdir` каталога
журнала (ровно один победитель среди параллельных прогонов — проигравшие
идут обычными прогонами), запись рождения (версия создающей машины),
генезис-звено цепочки по начальным строкам потока и штатные файлы зоны,
записанные из канона. Ничто другое никогда не создаёт инстанс, и только
первая непустая строка потока его запускает. Аналогия: первый пробой в
свежей ленте. → инстанс, → поток.

**Сборка** — необязательная заявленная команда корпуса. Когда стоит,
она идёт ПЕРВОЙ на каждом запуске, раньше любого ряда, под тем же
законом исполнения, что и ряд. Сборка, выходящая не нулём, виснущая за
→ дедлайном или не стартующая, красна на весь прогон: каждый ряд
заморожен — ничего не исполняется, ничего не движется, кроме
собственного журналируемого факта сборки. Заявление сборки в документе
заменяет стоящую; отсутствующее поле хранит её. Артефакты заявленной
сборки — работа: они законно двигают дерево. → прогон, → заморозка
красной сборки.

C

**Вызов** — весь интерфейс машины: `punchtape`, без аргументов, где
угодно на рабочем корне или ниже. Всякий ответ за пределами одной
строки терминала — файл → зоны. → строка терминала, → код выхода.

**Candor** — `law:candor`, закон громкой записи: ничто пропущенное,
разрешённое или отложенное работой не проходит в тишине. Громкая
оговорка со своей причиной и своими ссылками; мандат, называющий
строку и заменяемую вещь; приказы с настоящими состояниями,
откладывания со своими причинами; заметки с разрешимыми ссылками;
проза везде непуста — каждая пометка такова, что человек может её
взвесить. Отказ со ссылкой candor называет тихую дыру.
→ мандат, → оговорка (громкая), → заметка, → Id законов.

**Канон** — единый встроенный источник всего, что машина печатает как
закон: английский контракт (база и линейка), русский и китайский
зеркала (данные для людей), шаблон документа, страница справочника со
своими зеркалами, пример, карта законов и правило среды. Контракт,
шаблон и справочник зоны генерируются из него при рождении и
обновляются при его смене; пример, который солгал бы о машине, роняет
сборку. → контракт, → карта законов, → справочник.

**Канонические байты** — одно официальное написание документа: строгий
декод в модель, затем канонический маршал (отступ в два пробела,
отсортированные ключи отображений, поля в порядке объявления,
написание команды автора сохранено). Два написания одного содержания —
одно содержание: машина сравнивает и журналирует только канонические
байты. Пример: пере-отступленный `inbox.yaml` — та же подача, что и
исходный.

**Носитель** — то, что несёт заявленный исход: ответ несёт свой
текст, исполнение — свою команду; работу и описание несёт
требование, чьи строки несут строку; пометку несёт маркер на ней;
вопрос несёт ждущий приказ того же документа. Носитель обязан
стоять в той же подаче, что заявляет исход; снятие носителя
заново открывает строку. → интент, → исход,
→ неразрешённые строки.

**Цепочка** — sha256-хребет прошлого → потока: каждая запись
demand-append несёт хэш по байтам предыдущего звена, соединённым с
новыми строками. Каждый прогон пересчитывает всю цепочку от генезиса по
текущим байтам; звено, не воспроизводящееся, — → повреждение зоны, и
прогон никогда не начинается. Прошлое неизменно; хвост открыт.

**Клейм** — диапазон строк дерева, на котором стоит поведение:
`path/file.go:12-48`, от корня, first ≤ last. Один диапазон именует
одно поведение — уже держащийся клейм отвергается у второго держателя.
Байты заявленных строк питают дайджест клеймов поведения внутри каждого
→ пруфа; изменение внутри клейма делает ряды поведения устаревшими.
Покрытие живёт в заявленных строках, никогда в глобах.

**Чистая среда** — база, которую видит каждая команда машины: ровно
имена, объявленные каноном, — `PATH` и `HOME`, — взятые из шелла,
запускающего машину, плюс → закрепления зоны, ничего больше. Реально
переданный набор вместе с версией машины, архитектурой и релизом ядра
образует → хэш среды.

**Акт завершения** — подпись: `inbox.yaml`, несущий ровно `done: true`
и ничего больше. Не документ — голая осознанная дверь к → вердикту.
Прогон продолжает обычные шаги, и шаг вердикта решает: каждый гейт
зелёный — вердикт записан; чего-то не хватает — отчёт называет дыры.
Считается собственным журнальным фактом, отдельно от подач.
→ прогон, → done.

**Контракт** — весь закон машины одним текстом (`contract.md` в зоне,
из канона), печатаемый целиком в терминал при → первом контакте и
всякий раз, когда зона стоит нерождённой. Восемь законов с id —
`law:demand` (поток, его нумерация, исходы и дерево, не движущееся под
тихими интентами), `law:document` (единый формат и его законы слияния),
`law:paths` (только относительные корню пути), `law:claims` (покрытие
диапазонами строк и вселенная), `law:proof` (пинованные байты, один
run — одно поведение, устарелость), `law:candor` (громкая отметка,
мандат, приказы), `law:done` (акт завершения и гейты вердикта),
`law:your-tree` (среда исполнения) — плюс цикл, файлы зоны и вызов.
Английский текст правит; зеркала несут тот же набор законов.

**Корпус** — стоящий документ: поведения, реестр и команда сборки, как
они стоят после каждой принятой подачи. Его канонические байты живут
как `corpus.yaml` (генерируемый образ, восстанавливаемый каждый прогон) и внутри
подписи вердикта. → версия корпуса.

**Версия корпуса** — счётчик принятых подач: каждое принятие поднимает
его на единицу. Вердикт записывает версию, на которой он вынесен;
строка вердикта `state.md` называет обе, а следующая инструкция
различает «вердикт стоит на текущей версии» и «всё зелёное, акт
следующий». → вердикт.

**Covers** — заявление поведения о пруфе: список id требований, за
которые стоят ряды поведения. Cover обязан назвать требование, стоящее
после слияния подачи; снятие требования требует той же подачей разобрать
каждый его cover. Стоящее требование, которое не покрывает ни одно
заявляющее поведение, — → сирота и держит вердикт.

D

**D-диапазон** — единое написание строк потока: `D<n>` или
`D<a>..D<b>` по возрастанию, через запятую (`D1..D4, D9`). Номера
именуют непустые строки потока по порядку файла, выводясь заново из
байтов на каждом прогоне; спаны требований, строки маркеров, строки
интентов и спросы приказов ездят на этой грамматике, и машина выводит
наборы чисел обратно в ней со схлопнутыми последовательностями
(`D19, D23..D25`). → поток, → требование, → маркер.

**Дедлайн** — потолок, под которым идёт каждая команда машины — каждый
ряд, сборка и каждое исполнение: на дедлайне вся процессная группа
убивается, и факт гласит `timed out after Ns`. Дефолт — 300 секунд;
зона поднимает его одним пином — `PUNCHTAPE_ROW_TIMEOUT` называет целые
секунды. Убийца зависаний, никогда не судья медленной работы: машина
ограничивает, сколько одна команда может висеть, а не сколько агент
может работать. → процессная группа, → заморозка красной сборки,
→ закрепления.

**Отложенный приказ** — → приказ, отложенный со своей причиной: вопрос
остаётся видимым на странице состояния навсегда (`deferred orders:` со
спросом, вопросом и причиной), но вердикт не держит. Видимая метка
«человек сказал потом». → ждущий приказ.

**Описание (describe)** — один из шести → исходов: строка просит
описание того, что стоит, носимое требованием, чьи строки несут строку.
Как ответ и исполнение, описание запирает дерево: описывать не разрешено
двигать проект. → замок дерева.

**Дайджест** — единица идентичности машины: sha256 точных байтов, в hex.
Те же байты — тот же дайджест, другие байты — другой дайджест с
подавляющей вероятностью. Дайджесты сводят мир машины: дайджесты
диапазонов строк, дайджесты клеймов, пруфы, адреса объектов, дайджест
дерева, подпись вердикта. Человеческие написания режут его до первых
двенадцати знаков — → токен. Аналогия: отпечаток пальца — не сам
палец, но достаточный, чтобы назвать его. → хранилище объектов,
→ пруф.

**Done** — `done: true`: двухсловный акт завершения, ровно это и ничего
больше в документе. Любое другое поле рядом с флагом отвергается — голый
акт и есть суть. → акт завершения.

**Дрейф** — производный факт, что дерево двинулось под стоящим
вердиктом: дайджест клеймов сертифицированного поведения больше не равен
записанному указателю вердикта. Ничто ничего не наблюдает — сравнение
есть арифметика над журнальными фактами и свежими дайджестами. Строка
вердикта на странице состояния говорит `open (drift since run N)` —
первый прогон после вердикта, увидевший сдвиг, — и дрейф разрешается
только подачей, приземлившейся после того прогона-свидетеля. История
вердиктов называет прогон, поймавший каждый дрейф, и прогон, который его
восстановил (первый позднейший прогон без красных рядов). → история
вердиктов.

E

**Хэш среды** — отпечаток того, что видят команды: версия машины,
`GOOS/GOARCH`, релиз ядра и отсортированный набор `NAME=value`,
реально переданный (чистая база плюс закрепления, пин дедлайна включён).
Он входит в каждый → пруф: сессия, сменившая среду, двигает пруфы —
ряды устаревают, никогда не зеленея ложно.

**Эпоха** — один нумерованный файл потока журнала
(`epoch-NNNNN.yaml` под `journal/`): записи дописываются в живую эпоху,
один YAML-документ за сепаратором `---` в начале строки. Принятая подача
ротирует поток до того, как её записи лягут, — записи каждой подачи
живут в своей эпохе; ротация никогда не складывает пустых файлов.
Загрузка читает каждую эпоху в порядке номеров. → журнал, → оборванный
хвост.

**Код выхода** — единственный двоичный ответ вызова: 0 — машина
отработала (красные ряды — данные, не ошибка); 1 — вызова не было
(повреждение зоны, журнал, не сумевший загрузиться, машинная запись, не
сумевшая встать, дурная строка закрепления или вселенной, чужая версия
машины, аргументы на строке).

**Оговорка (громкая)** — открытое вычёркивание реестра: реальный
незакрытый диапазон строк, помеченный причиной, цитирующей строку
потока или закон, со ссылками, которые разрешаются. Оговорка, не
накрывающая ни одной незакрытой строки, отвергается — отметка, ничего
не отмечающая, есть шум; пустая причина отвергается так же. Сливается по
диапазону; снимается ключом диапазона. Громкие оговорки завершают
арифметику «дерево = клеймы» вердикта. → дыры, → черновик оговорок.

**Черновик оговорок** — `exclusions-proposal.yaml`, собственный черновик
машины списка оговорок: каждая стоящая дыра как готовый диапазон с
пустой причиной и refs — автор дописывает причины и выбрасывает
занимаемое. Генерируется из машинной арифметики дыр; без стоящих дыр
черновик уходит. Машина пишет пути; суждение остаётся вашим.

**Исполнение (execute)** — один из шести → исходов: строка просит саму
машину запустить команду, носимую интентом (`run`). Исполнение ложится
между подачей и рядами — exit и stdout журналируются (целиком до 4096
байт, свыше — адрес в хранилище объектов), дерево заперто на прогон.
→ факт исполнения.

**Факт исполнения** — журнальная запись одного исполнения, сделанного
машиной за агента: прогон, отвеченные строки, команда, exit, дайджест
stdout и сам stdout. Последнее исполнение показывается на странице
состояния и в отчёте. → исполнение.

**Expect** — требование ряда к тому, что оставляет команда: любая смесь
`rc` (точный код выхода; отсутствует = 0), `out` (stdout: точные байты
или подстрока за префиксом `contains: `) и `files` (относительные корню
пути, читаемые после прогона, те же два написания сравнения). Хотя бы
одно поле обязано стоять — пустой expect отвергается. Сравнение чисто:
никакого толкования нигде. → пинованный ряд.

F

**Первый контакт** — запуск без `.punchtape` на рабочем каталоге или
выше: машина печатает весь контракт и выходит 0, ничего не создавая.
Полностраничное исключение терминала — файлового канала ещё нет, и сам
закон есть ответ. Та же страница печатается для каталога зоны, стоящего
без журнала, что бы он ещё ни нёс.

**Свёртка** — перестройка настоящего из прошлого: все записи журнала,
от старых к новым, проигранные в → стоящее — рождения фиксируют
происхождение, подачи двигают корпус и применяют носителей, прогоны
ставят факты рядов, вердикты стоят, отказы и завершения считаются. Одни
и те же записи всегда сворачиваются в одно и то же стоящее. Аналогия:
проигрывание перфоленты с начала — лента есть истина, память машины
производна.

G

**Зелёный** — стояние ряда: он запускался, и каждое его ожидание держалось
(список сломанных фактов пуст). Зелёный ряд, чей → пруф ещё стоит, —
→ остаётся зелёным: не исполняется повторно. Корпус зелёный, когда
каждый ряд зелёный; только зелёный корпус с пинованными пруфами может
закрыть вердикт.

H

**Дыры** — незакрытые строки дерева: строки, не названные ни одним
→ клеймом и ни одной громкой → оговоркой. `state.md` называет первые
десять файлов со счётами и максимальными диапазонами; `holes.md` несёт
весь реестр без ограничения; незакрытая строка держит следующий вердикт.
Написание диапазона, которое не парсится, или строка за пределами строк
файла не клеймит ничего — названные ею строки остаются честными дырами.
→ обход дерева, → черновик оговорок.

I

**Inbox (слот подачи)** — `inbox.yaml`, единый входной файл зоны. Его
присутствие значит, что подача ждёт: документ декодировать, валидировать
и принять — или → акт завершения — или → отказ, ничего не меняющий
(байты стоят, автор правит названное место и запускает снова). Его
отсутствие — обычное состояние. Всё, что входит в машину, входит через
этот один файл.

**Инстанс** — одна задача машины: рабочий корень, его зона `.punchtape`
(журнал, объекты, страницы, слоты) и блок AGENTS в корне. Рождается один
раз, никогда не умирает; действительно новая задача — новый поток в
свежем каталоге. Одна зона обслуживает одну версию машины: зона,
рождённая другой версией, отвергается — архивируй и начни заново.
→ рождение, → зона.

**Интент** — заявленный → исход новых строк потока: какие строки, какой
из шести исходов, пересказ агента прозой — и собственный носитель
исхода внутри того же документа. Каждая новая строка объявляется ровно
одним интентом в подаче, которая её встретила; строка, уже несущая свой
исход, никогда не переобъявляется. → ответ, → исполнение, → описание,
→ работа, → пометка, → вопрос.

J

**Журнал** — единственный источник истины: под `journal/` живёт поток
записей, в который только дописывают; каждая принятая подача открывает свежую эпоху. Десять
родов записей — birth, submission, demand-append, no-new-demands, run,
execution-fact, tree-lock, verdict, refusal, completion — каждый ровно
со своей нагрузкой, без меток времени где-либо: порядок — место
записи, идентичность — её байты. Журнал одной истории байт-идентичен на
каждой машине. Всякий иной файл зоны — его генерируемый образ. Никогда
не правится руками. → свёртка, → стоящее, → оборванный хвост.

K

**Остаётся зелёным** — зелёный ряд, чей записанный пруф равен текущему:
ряд не исполняется, не читается, не трогается — его записанный зелёный
стоит. Вся экономика машины: неизменные входы ничего не стоят.
→ пруф, → устаревший.

**Знание** — файл памяти зоны `knowledge.md`: каждая заметка каждой
принятой подачи ровно один раз (пронумерованная, со своим видом и
ссылками), затем записи → уроков, сгруппированные по причине.
Генерируется из журнала; сами заметки никогда не толкуются.

L

**Id законов** — восемь поименованных законов контракта, словарь каждого
отказа: `law:demand`, `law:document`, `law:paths`, `law:claims`,
`law:proof`, `law:candor`, `law:done`, `law:your-tree`. Отказ всегда
цитирует один — поименованное правило и контракт всегда говорят об одном
и том же. → отказ.

**Карта законов** — таблица паритета канона: каждое правило валидации
привязано к закону, который печатает контракт, и каждый цитируемый закон
— к напечатанному контрактом. Что принуждается, то печатается; что
печатается, то принуждается.

**Урок** — один красный, ставший зелёным, закреплённый как чистые
данные: класс
причины, ключ ряда, сломанные факты, байты ряда до и после (отвечает
журнальный индекс байтов рядов) и два номера прогонов. Пишется самой
записью прогона — ноль токенов любой модели. Уроки попадают на страницу
знаний, сгруппированные по причине. Пример: ряд красный на `exit: got
1, want 0` на прогоне 4, зелёный на прогоне 5 — урок несёт оба ряда и
оба номера.

M

**Машина при рождении** — версия машины, которую несёт запись рождения:
факт происхождения инстанса, печатаемый страницей состояния
(`machine at birth:`). Зона, рождённая любой другой версией,
отвергается до сворачивания единой записи. Версия также входит в хэш
среды, и новая машина честно обнуляет старые пруфы. → рождение,
→ хэш среды.

**Прогон** — одно исполнение вызова после рождения: проверка цепочки,
шаг подачи, исполнения, сборка, отпечатки, исполнение устаревших рядов,
журналирование, вердикт, рендер. → Номер прогона считает только прогоны,
сменившие факты (сборка шла, ряд исполнялся, исполнение легло); прогон,
который мерил и рендерил, ничего не меняет.

**Мандат** — разрешение заменять стоящую работу: строка потока,
приказавшая изменение, и стоящее, которое он разрешает заменить, — id
поведения или требования, заменяемое той же самой подачей. Подача,
заменяющая или снимающая стоящую работу без мандата, отвергается;
мандат, называющий то, чего эта подача не заменяет, отвергается так же.
Строка доказывает существование, не смысл — цитата для аудитного глаза.
→ candor.

**Маркер (not-a-requirement)** — вычёркивание реестра: строки потока,
объявленные ничего не требующими, с причиной, которую читатель может
взвесить. Строка либо требование, либо нет — никогда оба: маркер на
строке требования отвергается. Сливается по фолду строк; снимается
D-грамматическим ключом. Пример: строка-заголовок, помеченная причиной
«заголовок, не требование».

**Слияние** — законы подачи: поведения сливаются по id (перечисленная
голова заменяется целиком — name, prose, claims, covers — ряды сливаются
по → ключу run); требования сливаются по id; маркеры — по своим строкам,
оговорки — по диапазону, приказы — по паре требование-вопрос; снятия
уходят первыми; `remove` снимает стоящие ключи; отсутствующее поле ничего
не меняет; снять-и-пере-добавить одной подачей — свежее. Экономика:
число подач никогда не влияет на цену — неизменённые ряды не пересылаются.

**Пометка (mark)** — один из шести → исходов: строка ничего не требует,
носимая → маркером на ней. Пометка громка по построению — причина,
письменно, навсегда в корпусе.

N

**Следующая инструкция** — единый императив машины, тот же текст в
строке терминала и строке `next:` `state.md`: отказ говорит править
названное место в inbox; красная сборка говорит чинить сборку; пустой
корпус говорит подать первый документ; реестр без поведений говорит
подать поведение с пинованным рядом; каждый блокер вердикта говорит свою
инструкцию; вердикт, стоящий на текущей версии корпуса, говорит показать
`state.md` человеку; всё зелёное говорит написать `done: true` и
запустить, чтобы записать вердикт. У каждого состояния, в котором может
стоять машина, ровно одна инструкция — никогда две правды.

**No-new-demands** — подписанное заявление, что новых слов человека не
пришло: число строк потока в момент подписи и прогон, который подписал,
журналируются рядом с принятой подачей. Подпись над словами, которые всё
же пришли, стоит в журнале навсегда — единственная точка, где защита —
видимость, а не гейт: страница состояния несёт подпись, а слова остаются
незажурналированными и объявимыми. Следующий demand-append снимает
стоящую подпись.

**Заметка** — структурированный свободный текст документа: один из пяти
видов (directive, decision, exclusion, lesson, work), текст и ссылки,
обязанные разрешаться, — строка потока, стоящее требование или поведение,
разбираемый диапазон строк или id закона, который печатает контракт.
Машина никогда не толкует заметку; она несёт и индексирует её. Канал для
людей, не канал в машину.

O

**Хранилище объектов** — хранилище по содержимому под
`journal/objects/`: имя объекта — sha256 его байтов; файл —
`<first two hex>/<remaining sixty-two>` под корнем хранилища. Одинаковые
байты хранятся один раз — дедупликация по построению; каждая запись
перечитывается и сверяется, каждое чтение сверяет свой дайджест.
Канонические байты каждой принятой подачи и каждого слитого поведения
живут здесь, неизменные. → дайджест.

**Приказ (открытый)** — один вопрос, стоящий перед человеком: строка
потока, к которой он относится, сам вопрос и его состояние — → ждущий или
→ отложенный. Ждущий держит вердикт; отложенный остаётся видимым навсегда
со своей причиной. Сливается по паре требование-вопрос; факты рождения
приказа — машинные. → вопрос.

**Сирота-требование** — стоящее требование, которое не назвал в covers
ни одно стоящее поведение с клеймами. Держит вердикт (`the requirements
… stand uncovered by any behavior's covers`). → covers.

**Исход** — шесть написаний того, чего просит строка потока: `answer`,
`execute`, `describe`, `work`, `mark`, `ask` — собственный словарь
протокола, заявляемый → интентом в момент появления строки. Ответ и
исполнение несут себя сами (text, run); остальные четыре лежат в реестре
того же документа. Строка без исхода — → неразрешённая строка.

P

**Закрепления** — объявления среды зоны: файл `env`, одна строка
`KEY=VALUE`, ключ `[A-Za-z_][A-Za-z0-9_]*`, имя пинится однажды, без
`export`, без кавычек, без абсолютных путей (закрепление путешествует с
деревом). Комментарии и пустые строки проходят, терпится хвостовой
перевод каретки. Строка любой другой формы — громкий отказ, называющий
файл, строку и закон. Закрепление побеждает по имени над чистой базой;
каждое закрепление входит в хэш среды. Пример: `TOOLS=tools/bin` —
значение может быть относительным путём, никогда абсолютным.

**Пинованный ряд** — ряд, чей expect пинит точные байты: `out`, не
являющийся ни пустым, ни префиксом `contains: `, или `files`, где каждое
значение пинит точные байты. Пинованный ряд — пруф поведения; всё
остальное — комментарий. `rc` один не пинит ничего — зелёный код выхода
доказывает лишь, что команда закончилась. Каждое поведение несёт хотя бы
один пинованный ряд, иначе подача отвергается.

**Процессная группа** — дисциплина запуска: каждая команда машины идёт
в своей группе, и всё, что она оставила живым (серверы, воркеры, всё,
что поднял шелл), убивается вместе с группой — сигнал смерти группе и
процессу, затем ограниченное ожидание фактической смерти. Остатки ряда
никогда не переживают ряд.

**Пруф** — отпечаток ряда: sha256 по каноническим байтам ряда, дайджесту
клеймов его поведения и → хэшу среды. Пока записанный пруф равен
текущему, ряд → остаётся зелёным; движение любого из трёх делает его
→ устаревшим. Аналогия: сургучная печать над рядом, его входами и его
окружением — сломай любое, печать сломана.

**Проза** — слова, которыми владеет автор: раскрытие требования человеческими
словами, история поведения о том, что получает пользователь, пересказ
строки интентом. Обязательна и непуста; переносится дословно на страницы
спецификации и в трассу. Машина проверяет наличие, никогда качество —
чтение принадлежит человеку.

R

**Красный** — стояние ряда: он запускался, и хотя бы одно ожидание сломалось
(сломанные факты, журналируемые как измерено, есть причина). Красные
ряды группируются по причине в отчёте. Закон пропуска дальтоник: стоящий
красный перезапускается ровно тогда, когда его → пруф движется — его
входы сменились, — тот же закон, что держит зелёный ряд зелёным; но
стоящий красный никогда не проходит за сделанный, потому что → вердикт
читает статус факта, никогда одни пруфы. Красные ряды под стоящим
вердиктом — → дрейф.

**Заморозка красной сборки** — закон, что упавшая сборка останавливает
всё: ни один ряд не исполняется этим прогоном, ни один факт ряда не
движется; запись прогона несёт только факт сборки, а следующая
инструкция говорит `build red`. Подача, прошедшая тем же прогоном, всё
равно принимается — корпус движется, ряды ждут.

**Справочник** — `reference.md`, собственная страница-мануал зоны:
все двери машины на одной странице — вызов, поток, документ,
интенты, реестр, слияние, исполнение, юниверс, вердикт, страницы,
закрепления, повреждение, константы — написанные в каноне,
генерируемые в зону при рождении и обновляемые при каждой смене
канона. Полное знание всегда под рукой, чтобы агент никогда не
гадал. → канон, → контракт, → шаблон.

**Отказ** — ответ машины сломанной подаче: одна строка на сломанное
правило — точное поле, → id закона, измеренный факт. Байты подачи ничего
не пишут; сам отказ журналируется как собственный факт машины и
считается на `state.md`; документ стоит в `inbox.yaml`, автор правит
названное место и запускает снова. Пример:
`behaviors[0].rows[1].expect: the expect is empty — name rc, out
or files (law:document)`. → валидация.

**Реестр** — корпусной учёт слов: требования (каждое со своими спанами
строк потока), маркеры, громкие оговорки и открытые приказы. Сливается
по законам подачи; дайджестируется целиком в → дайджест реестра
вердикта.

**Дайджест реестра** — sha256 по каноническим байтам требований, маркеров,
исключений и приказов вместе — весь счёт слов, запечатанный одним
дайджестом и переносимый записью вердикта.

**Remove** — список снятий документа, пять написаний: id требования, id
поведения, ключ маркера-или-приказа `D<n>`, ключ оговорки
`path:first-last` — и пятое, не являющееся ни одним из них: оно
не именует стоящего и отвергается. Каждый ключ обязан стоять; снятия
уходят первыми в слиянии; снятие требования переоткрывает его строки и
требует той же подачей переподвесить каждый его cover; поведение
снимается целиком со своими рядами, под → мандатом.

**Отчёт** — `report.md`: вся картина последнего события, сменившего
факты, — для прогона строка сборки, исполнения, счёт зелёных и каждый
красный ряд, сгруппированный по своей сломанной причине, плюс заметки
вердикта,
когда говорил акт завершения; для отказа строка на отказ и указатель
правки. Пишется целиком, когда движется; прогон, ничего не сменивший и
ничего не закрывший, оставляет предыдущий отчёт стоять. → отказ,
→ вердикт, → страницы.

**Требование** — один спрос, сделанный конкретным: id (`R` плюс буквы,
цифры и точки, скажем `R1`), строки потока, которые он занимает
(D-диапазоны), раскрытие прозой, необязательный родитель `refines`.
Сливается по id; снимается только явным `remove`, который также чистит
каждый его cover. Поток разобран целиком, когда каждая строка несёт
свой исход и своего носителя.

**Ряд** — одна исполняемая проверка внутри поведения: одна команда
(`run` — строка шелла или список argv) и её → expect. Канонические байты
команды — → ключ run ряда и часть его → пруфа; место ряда в поведении —
его журнальный ключ (`<behavior id>/<index>`). Ряды — всё, чем
поведение доказывает.

**Ключ run** — канонические байты команды, ключ слияния ряда:
поданный run, который стоит, заменяет тот ряд целиком на месте; новый
run дописывается; неподанные ряды стоят. Пере-написанная команда —
новый run: стоящий стоит; одна команда доказывает одно поведение.
Пример: `./tool src out` (строка шелла) и
`["./tool", "src", "out"]` (argv) — два разных run: один через
шелл, другой напрямую.

**Номер прогона** — счётчик прогонов, меняющих факты. `run <N>` строки
терминала, шапки отчёта, состояния, трассы, знания и спецификации — все
называют одно число. Отказ не расходует номера прогона — он считается своим
собственным счётчиком.

S

**Подпись (вердикта)** — sha256 по каноническим байтам корпуса плюс, на
каждое поведение в порядке самого корпуса, `\0 id \0 claims digest`:
спека и точное состояние дерева, на котором она вынесена, одним
дайджестом. Показывается коротко (двенадцать знаков) на странице
состояния и в истории вердиктов.

**Дерево спецификации** — каталог страниц `spec/`: `index.md` плюс маленькая
страница на каждое живое поведение — id и имя, номер прогона, Story,
Demands, которые оно отвечает, Claims со своими дайджестами на диапазон,
Rows со своими стояниями пруфов, команды Verify. Страницы снятых
поведений уходят — дерево есть образ стоящего корпуса, ничего больше.

**Устаревший** — стояние ряда: его → пруф двинулся (его байты, заявленные
строки его поведения или среда) — или он ни разу не запускался — или его
поведение не заявляет клеймов. Устаревшие ряды исполняются на следующем
прогоне; инструкция считает их (`N row(s) stale — run again to execute
them`).

**Стоящее** — настоящее, перестроенное из журнала → свёрткой: факты
рождения, цепочка, версия корпуса и сборка, реестр, поведения и их
порядок, факты рядов и индекс байтов рядов, исходы строк и носители,
номер прогона, вердикт, счётчики, уроки, холд замка дерева. Всё, что машина
решает, она решает по стоящему — а стоящее всегда выводимо из одних
записей.

**Страница состояния** — `state.md`: стоящее на одной странице — учёт
слов и неразрешённые строки, очередь, подпись, версия корпуса, счётчики,
машина при рождении, вердикт со своей меткой дрейфа, историей и
отложенными приказами, строка на поведение, незакрытые и исключённые
строки, счётчики знания и `next:` — тот же текст, что строка терминала.
→ стоящее, → страницы.

**Поток** — сами слова человека: `demands.md`, открытый навсегда, каждая
непустая триммированная строка пронумерована D1..Dn по порядку файла.
Слова записывает в файл агент; машина берёт их сама на следующей
подаче (никогда не перепечатанными в документы), запечатывает прошлое
→ цепочкой и журналирует слова каждой подачи или её подпись
→ no-new-demands. Тронутая прошлая строка — → повреждение зоны.

**Подачи** — принятые документы, считаемые на `state.md` рядом с
отказанными и завершёнными — три отдельных экономики: документы, взятые
слотом, подачи, которые он отверг, и акты завершения, закончившие
работу.

T

**Шаблон** — `template.yaml`, генерируемый из канона при рождении и
обновляемый вместе с ним: форма документа с обучающими комментариями —
каждое поле, четыре правила YAML-кулинарии, написания remove.
Скопируйте, отредактируйте, подайте как `inbox.yaml`. Документ, который
декодируется, но ломает правило, всё равно отвергается — шаблон учит
форме, валидация держит закон.

**Строка терминала** — одна строка вывода вызова при успешном прогоне:
`punchtape: run <N> — <instruction>`. Инструкция называет файл, которого
коснуться, и есть тот же текст, что строка `next:` `state.md`.
Исключения: первый контакт печатает весь контракт; нерождённая зона
печатает свою однострочную инструкцию; вызов, который не может
случиться, отвечает своей единственной строкой ошибки — выход 1. Всё
остальное, что машина имеет сказать, живёт в файлах зоны.

**Токен** — человекочитаемое короткое написание → дайджеста: его
первые двенадцать hex-знаков. Подписи вердиктов и пруфы рядов на
странице состояния, токены поведений на страницах spec, токены
клеймов на трассе — всё токены; глаз сравнивает их, машина
сравнивает полные дайджесты. Токен — для чтения; полный дайджест —
идентичность. → дайджест.

**Оборванный хвост** — журнальная запись, обрезанная посреди записи
(крах, потеря питания). Она не ослепляет машину: целые записи грузятся,
оборванные байты уходят в карантин (`<epoch>.torn`), и файл эпохи
перестраивается байт-в-байт из целых записей. Кусок, не парсящийся вне
конечной позиции, — повреждение руками: честная ошибка. → эпоха.

**Трасса** — `trace.md`: витрина потока — каждая строка со своим текстом,
заявленным исходом, пересказом и носителями под ней (требования,
поведения с клеймами и рядами-пруфами, маркеры, ответы, последние
исполнения, приказы). Ничто не судится; всё положено для глаза. Одна
страница, построенная для аудитного взгляда человека.

**Дайджест дерева** — собственный отпечаток рабочего дерева: sha256 по
отсортированным строкам `path\0digest` каждого считенного файла —
бинарники включены своими байтами, зона и учёт систем контроля версий
исключены по имени. Измеряется до и после запертой подачи: двинувшийся
дайджест — журнальный факт → замка дерева.

**Замок дерева** — холд против тихого движения: подача, чьи интенты
стоят и ни один не `work` (и ни одной сборки нет и не заявлено —
артефакты сборки есть легальная работа), запирает дерево на свой прогон.
Дайджест измеряется до и после; движение журналируется и держит вердикт,
пока байты не вернутся или изменение не будет подано как заявленная
работа. Work-интент снимает стоящий холд и не вооружает новый.
→ ответ, → исполнение, → описание.

**Обход дерева** — единственный способ машины видеть рабочее дерево:
один упорядоченный обход, пропускающий зону (`.punchtape`) и каталоги
учёта систем контроля версий (`.git`, `.hg`, `.svn`) по имени, где бы
они ни стояли, фильтрующий по объявленной → вселенной, считающий строки
каждого внутреннего файла и дайджестирующий его байты, и считающий
внешние файлы по имени — громко, никогда не читая. Файл с NUL-байтом,
пустой или нечитаемый стоит вне вселенной покрытия целиком, с названной
причиной. Машина никогда не читает содержимое дерева как код — только
как байты для дайджеста и команды для исполнения. → кэш обхода.

U

**Незакрытые строки** — дыры дерева: строки, не названные ни клеймом, ни
громкой оговоркой. Называются пофайлово со счётами и максимальными
диапазонами — первые десять файлов на странице состояния, весь реестр в
`holes.md`, черновик в proposal оговорок. Незакрытая строка держит
следующий вердикт; стоящий вердикт может жить над ними — на виду
(`standing over N uncovered lines`). → дыры.

**Вселенная** — необязательное объявление зоны о том, что считается:
`.punchtape/universe`, один относительный корню путь в строку, `#` —
комментарий, без объявления — всё дерево. Корень, не именующий ни одного
файла дерева, отвергается громко — никогда тихая потеря покрытия.
Файлы вне вселенной стоят посчитанными на странице состояния, никогда не
судимыми. → обход дерева.

**Неразрешённые строки** — строки потока без заявленного → исхода или
без стоящего носителя заявленного исхода: «no outcome», «work pending»,
«describe pending», «mark pending». Называются с причинами на странице
состояния и в трассе; неразрешённая строка держит вердикт. Снятие
носителя переоткрывает его строку.

V

**Валидация** — весь набор правил, который документ проходит до принятия:
строгий декод и проход брони; алфавиты и единственность id; D-грамматика
против вселенной потока; носители исходов в том же дыхании; клеймы —
диапазоны строк, которые несёт дерево, один диапазон — одно поведение;
поведения с именами, стоящими covers, рядами с ожиданиями, хотя бы одним
пинованным рядом, единственным в рядах и между поведениями run'ами;
маркеры вне строк требований; оговорки над реальными дырами с цитирующими
причинами; приказы на стоящих строках с реальными состояниями; мандат
для заменённой стоячей работы; заметки с разрешающимися ссылками; remove,
именующий стоящее; done-документ ровно голый — плюс собственные гейты
машины: висячие covers, дубль клейма, закон закрытия ask. Каждый отказ
называет поле, факт и id закона. → отказ.

**Вердикт** — провозглашение машиной сделанного, записываемое только по
→ акту завершения и только когда каждый гейт стоит: заявленная
сборка зелёная; корпус непуст; каждый
ряд зелёный на текущих отпечатках; каждое поведение доказано зелёным
→ пинованным рядом; поток разобран целиком; каждое требование покрыто;
дерево равно своим клеймам плюс громким оговоркам; ни одного ждущего
приказа; дрейф именован; ни одного холда замка дерева. Запись несёт
номер, версию корпуса, → подпись, → дайджест реестра, указатель клеймов
каждого поведения и закрывающий прогон; рядом ложится запись завершения.
Только-допись — новый вердикт никогда не переписывает старый. Чего-то не
хватает — `not yet` плюс строка на класс дыры в отчёте, в едином порядке,
который читают все страницы.

**История вердиктов** — производная хроника страницы состояния: каждый
записанный вердикт (прогон, номер, версия, короткая подпись); каждый
→ дрейф (прогон с красными рядами под стоящим вердиктом, с ключами
рядов); каждое восстановление (первый позднейший прогон без красных рядов).
Последние десять событий, остальные скрыты за многоточием. Чего журнал не несёт,
то история не говорит.

**Флаг версии** — `punchtape --version`, ровно это написание и одно на
строке: печатает `punchtape <version>` и выходит 0 до всякого состояния —
единственная уступка человеку; контракт её никогда не упоминает.
→ вызов, → код выхода.

**Страницы** — генерируемые файлы зоны: `state.md`, `report.md`, `trace.md`,
`knowledge.md`, `holes.md`, черновик оговорок, дерево спецификации,
`corpus.yaml`. Образы журнала — переписываемые целиком при смене
содержания, не трогаемые при её отсутствии; страница, которая не смогла
записаться, — громкий отказ (устаревшая страница — ложь).

W

**Кэш обхода** — `cache/tree`: верифицированный ускоритель обхода дерева,
одна запись на файл — путь, размер, mtime, число строк, дайджест. Файл,
чей размер и mtime остались такими, как их запомнил кэш, использует
кэшированные факты вместо своих байтов; пруфы никогда не спрашивают
кэш — заявленные
строки читаются напрямую, всегда. Пишется один раз в конце прогона,
только когда обход его двинул. Удалите его — следующий прогон пересчитает
те же числа: ускоритель, никогда источник истины. → обход дерева.

**Работа (work)** — один из шести → исходов: строка приказывает изменение
проекта, носимое требованием, чьи строки несут строку. Work-интент —
легальный способ двигать дерево: он снимает стоящий холд замка и не
вооружает нового. → замок дерева.

**Рабочий корень / рабочее дерево** — каталог, несущий зону (вызов находит
её на своём старте или выше) и всё рядом с ней. Дерево — территория
агента: машина обходит его, дайджестирует, исполняет в нём команды — и
никогда не читает его содержимое как код.

Z

**Зона** — `.punchtape/`, единственный каталог, которым владеет машина:
учебные страницы (`contract.md`, `template.yaml`, `reference.md`), слоты
(`demands.md`, `inbox.yaml`, `env`, `universe`), генерируемые текущие
файлы (`corpus.yaml`, `state.md`, `report.md`, `trace.md`,
`knowledge.md`, `holes.md`, `exclusions-proposal.yaml`, `spec/`), журнал
со своими объектами и машинные `cache/`, `tmp/` и `run.lock` —
собственный лок зоны: один прогон единовременно, ядро снимает его
и при смерти держателя. Никогда не правится руками; одна запись стоит вне её — → блок AGENTS в рабочем корне.
→ повреждение зоны.

**Повреждение зоны** — громчайший отказ машины: прошлое сломалось или
зона не этой машины для чтения. Тронутая прошлая строка потока,
урезанный или удалённый `demands.md` рождённого инстанса, журнальная
запись, не воспроизводящаяся, зона, рождённая другой версией машины,
повреждённые маркеры AGENTS — одна строка, выход 1, прогон никогда не
начинается. Журнал и цепочка держат прошлое; повреждение руками
называется, никогда не обходится догадкой.
